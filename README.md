# breachline

명령 하나로 띄우는 **스마트 팩토리 보안 실습장**.

가상 조립 라인을 실시간으로 관제하면서, 실제 산업 현장 위협(ICS 공격)을 직접 공격해 보고 방어를 켜서 막아 보는 오픈소스입니다. AI 관제 에이전트가 원인 분석과 조치 제안을 돕고, 그 에이전트 자체도 공격 대상이 됩니다.

> 개발 초기 단계입니다. 아직 실행할 수 있는 코드가 없습니다.

## 실습 방식

1. `docker compose up` 한 번으로 공장, 관제 화면, 공격 도구가 모두 뜹니다
2. 실습을 고르면 해당 방어가 **꺼진 상태**로 시작합니다
3. 가이드를 보며 공격하고, 관제 화면에서 피해를 확인합니다
4. 탐지 화면에서 흔적을 찾고, 방어를 켜는 코드와 설정을 봅니다
5. 같은 공격을 다시 실행해 막히는 것을 확인합니다

## 구성

| 폴더 | 내용 |
| --- | --- |
| `gateway/` | Spring Boot - 수집, 명령 중계·서명 검증, 권한·2인 승인, 감사 로그 |
| `agent/` | Python - AI 관제 에이전트 |
| `simulator/` | Python - 가상 설비 시뮬레이터 |
| `attacker/` | Python - 실습별 공격 스크립트 (실습장 네트워크 안에서만 동작) |
| `console/` | React + react-three-fiber - 2D·3D 관제 화면 |
| `labs/` | 실습별 가이드·풀이·확인 스크립트 |
| `docs/` | 시작하기, how-to, 레퍼런스, 설계 설명, 설계 기록(ADR) - [문서 지도](docs/README.md) |
| `infra/` | docker compose |
