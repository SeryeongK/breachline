# 실습

실습마다 방어가 **꺼진 상태**로 시작합니다. 공격해 보고, 흔적을 찾고, 방어를 켜서 같은 공격이 막히는 것을 확인합니다.

- 각 실습 폴더의 `README.md`는 가이드입니다. 스스로 풀어 보세요
- 막히면 `SOLUTION.md`를 여세요 (풀이 포함)

## 실습 폴더 구조

새 실습은 [`_template/`](_template/)을 복사해서 `NN-이름/`으로 만듭니다.

```
labs/
  01-unauthorized-control/
    README.md     가이드 (풀이 없음)
    SOLUTION.md   풀이
    verify/       "방어 끔=공격 성공, 켬=공격 실패" 자동 확인
```
